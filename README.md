# Модуль Beroo для OpenCart 3 / OcStore 3

Двостороння інтеграція магазину OpenCart із платформою **Beroo**.

- **OpenCart → Beroo:** замовлення, товари, категорії, опції товарів, рекламні джерела (UTM), експорт залишків.
- **Beroo → OpenCart:** створення замовлень і зміна статусів.
- Зіставлення способів оплати, доставки та статусів налаштовується безпосередньо в модулі (двосторонньо).

## Встановлення

1. Завантажте `beroo.ocmod.zip` зі сторінки [Releases](https://github.com/chernysh/beroo-opencart/releases/latest).
2. Адмінка OpenCart → **Розширення → Встановлення** → завантажте архів.
3. **Розширення → Модифікатори** → *Оновити*.
4. **Розширення → Модулі → Інтеграція з Beroo** → *Встановити*, потім *Редагувати*.
5. Вкажіть **домен Beroo** та **ключ форми** (з кабінету Beroo: «Маркетплейси → OpenCart»).
6. Увімкніть модуль і збережіть.

## Повний перенос на BEROO

Кнопка **«Імпортувати все на BEROO»** у налаштуваннях модуля (з'являється після збереження домену й ключа): BEROO фоном сам забирає із сайту категорії, товари (фото, опції → варіації, акційні ціни, атрибути), виробників, інформаційні сторінки, статті блогу (SEO CMS `record`/`blog`), SEO-сторінки фільтрів OCFilter (→ посадкові сторінки), FAQ, чинні купони, відгуки, покупців і всі замовлення з мапінгом статусів. Мета-теги переносяться (і головної сторінки теж), а старі SEO-адреси (разом із редиректами модуля redirector) стають 301-редиректами на нові сторінки. Каталог і сторінки — українською (якщо її немає — іншою мовою), статті — кожна мова окремо. Повторний запуск оновлює, а не дублює; статуси вже наявних замовлень і залишки вже наявних товарів не чіпає (їх веде BEROO).

Дані віддає ендпоінт `index.php?route=extension/module/beroo/export` (заголовок `X-Beroo-Key` = ключ форми). Те саме вручну на сервері BEROO:

```
python manage.py import_opencart --url https://site.com.ua --key <ключ форми> --dry-run
python manage.py import_opencart --url https://site.com.ua --key <ключ форми>
```

Редиректи будуються з SEO-адрес OpenCart. Динамічні сторінки фільтрів (OCFilter: будь-які комбінації значень, виробник у адресі) відомі лише з трафіку — передайте вигрузку Search Console «Ефективність → Сторінки» (`Сторінки.csv`): `--urls Сторінки.csv`. Кожна непокрита адреса веде на найближчу сторінку (сторінку фільтра, бренд у категорії, категорію).

## Сумісність

OpenCart / OcStore **2.3** та **3.0**.
